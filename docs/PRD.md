# EmOri PRD v0.5 — 최신 전달 반영 검토안

> **v0.5 정책 및 8단계 구현 · 2026-11-18.** 아래 확정 범위는 서버에 반영했다. 친구 복수 전송·생년월일·케어 최종 문구는 합의 전 제안이다. 아래 v0.3 원문은 과거 참고다.

> **MVP 음원 정책 확정 · 2026-11-18.** 팀이 미리 준비한 무가사 음원 중 최대 1곡(15초 이하)을 구슬에 선택적으로 첨부한다. 신규 구슬은 생성 대기 없이 전송할 수 있고, AI 생성·재시도는 MVP 범위에서 제외한다. 기존 AI 음원은 이미 저장된 기록에서 계속 재생할 수 있도록 보존한다.

**8단계 구현 상태:** 색 1~2개 선택과 서버의 색별 4단어 스냅샷, 선택적 사전 음원 첨부, 활성 카탈로그 조회, 비활성화 후 기존 구슬 재생을 구현했다. 기존 단어 ID 구슬·AI 기록은 조회 가능하다. 친구 복수 전송·생년월일 계약은 미합의로 보류한다. 케어는 보라·파랑의 매핑 단어 중 케어 대상이 있는 신규 구슬을 기존 날짜 집계에 포함하며, 과거 기록 소급 적용과 최종 안내 문구는 합의 사항이다.

## 최신 정책 및 검토 상태

| 항목 | 반영안 | 상태 |
|---|---|---|
| 로그인 | 아이디·비밀번호, 닉네임 기본값 아이디. 학교 인증 제외 | FE 전달 |
| 생년월일 | 신규 가입 시 입력, 기존 미입력자는 익명 설정 전 입력. 서버에서 연령 판정 | FE가 전달한 기획 결정; 생일 변경과 정확한 연령 경계 확인 필요 |
| 감정 | 색 1~2개, 다른 색 2개 혼합. 각 색에 해당하는 영역·단어 4개는 서버 자동 매핑 | FE가 전달한 기획 결정. 표의 실제 색·단어는 아래 v0.3 표 사용, 기획 확정본 확인 |
| 음원 | 사전 제작 15초 이하 무가사 샘플 중 선택적으로 1곡을 구슬에 첨부. FE가 파일 제공 | 확정 · 카탈로그에서 선택 또는 음원 없이 진행 |
| 친구 전송 | 친구 복수 선택 및 `friendIds` 배열 | FE 요구; 최대 인원·부분 실패 정책 확인 필요 |
| 수신·기록 | inbox에 orb, 기록에 counterpart. 익명과 복수 대상 counterpart는 null | FE 요구 |
| 케어 | 확정된 내 기록의 보라/파랑 매핑 단어 기준, 기획 제공 notice 사용 | 단어 매핑과 집계 정합성 확인 |

생년월일 입력은 **자기신고**이며 신원 또는 생년월일 인증이 아니다. 미입력은 UNKNOWN, 익명 활성화 불가. 학교 인증은 범위 밖. 향후 본인인증 요건 충족으로 표현하지 않는다. 개인 데이터 보유 기간·변경 허용 여부 결정 필요.

친구 여러 명 전송의 취소는 기존 대상별 취소와 FE의 전체 취소 요청이 충돌한다. 기존 대상별 취소를 유지하는 안을 제시하며 전체 취소는 의미·동시성 합의 전 미확정이다. 최초 열람·발신 기록 삭제와 수신자 보존·익명 한도·휴식 및 나머지 정책은 아래 v0.3 참고 범위에서 유지한다.

샘플을 선택하면 전송된 구슬과 이후 재열람에서 같은 음원이 재생된다. 카탈로그에서 숨긴 샘플도 이미 첨부된 기존 구슬에서 재생할 수 있다. 기존 기록의 열람·취소 정책을 적용한다.

## 구현 전 확인

1. FE가 제공한 샘플 파일의 제목·길이와 앱 내 사용 가능 여부 확인.
2. 친구 최대 수, 부적격 수신자 포함 시 전체 실패 또는 부분 성공, 친구·익명 대상별/전체 취소와 응답.
3. 나이 기준(만 19세 생일 기준 여부), 날짜 기준·2월 29일·재입력 정책과 개인정보 보유 기간.
4. 색별 단어 표 및 케어 분류·최종 안내 문구.

**저장소 반영 메모:** 위 v0.5 정책 중 확정 범위는 8단계에 구현했다. 아래 v0.3은 과거 계약 참고 자료이며, 실제 연동 방법은 [FE 연동 인계](FE_INTEGRATION.md)를 참조한다.

## 1. 적용 기준

우선순위는 ① 사용자의 이번 대화 결정 ② 최신 기획 ZIP의 추가 문서 「세부 정책 및 API 구현 기준 통합 문서」 ③ 같은 ZIP의 PRD 본문 ④ 기획에서 답하지 않은 항목에 대한 「API_FE_계약.md」 순이다. 명세 확정 전 BE 구현은 정책 근거로 사용하지 않는다.

이번 결정으로 감정은 색상 선택 후 단어를 선택하고, 음악은 감정 기반 AI ASMR 플레이리스트를 생성한다. FE의 색 단위 전송과 기존 제공 음원 카탈로그 방식은 변경 대상이다. 친구 단일 전송·익명 개별 취소·신고 사유·익명 차단·케어 최초 1회 노출은 최신 기획을 따른다.

표에서 **작업 기본값**은 사용자가 개별적으로 확정하지 않은 세부 사항을 이번 문서에서 구현 가능한 값으로 정한 것이다. **결정 필요**는 외부 연동 또는 기획 확인이 필요한 항목이다. 담당자가 변경 시 두 문서를 함께 수정한다.

## 2. 서비스 목표와 사용자 흐름

EmOri는 감정을 구슬로 표현해 자신에게 기록하거나 친구·익명 사용자에게 전달하고, 감정에 맞춰 생성한 ASMR을 다시 들을 수 있는 서비스다. 핵심 대상은 만 19~34세 대학생·취업준비생·사회초년생이다.

- 가입 → 로그인 → 홈 → 색상·단어 선택 → 선택적으로 AI ASMR 생성 → 미리보기 → 나에게/친구/익명 경로 선택 → 전달.
- 수신함·알림 → 최초 단일 구슬 화면 → 글로우 → 회전 재생. 익명 수신만 반응하기·조용히 듣기 제공.
- 기록장 → 구슬 상세 → 과거 수신 단일 화면 → 글로우와 기존 플레이리스트 재생. 새 구슬·수신·반응을 만들지 않는다.

## 3. 가입과 친구

### 연령 확인 — 결정 필요

최신 기획은 가입 단계 연령 확인과 만 19세 이상 익명 이용을 요구하지만 확인 수단을 확정하지 않았다. 기본 가입은 아이디·비밀번호·닉네임만으로 완료한다. 서버 adultStatus 기본값은 UNKNOWN이며, 연령 확인 전에도 나에게·친구 전송은 가능하다. 익명 활성화는 AGE_REQUIRED로 제한한다. 따라서 현재 상태만으로는 신규 사용자의 익명 이용 전체 흐름을 완료할 수 없다.

생년월일 자기 입력을 자격 확인으로 인정할지 또는 외부 인증을 사용할지 결정해야 한다. FE가 임의로 VERIFIED 상태를 보내는 API는 제공하지 않는다. 외부 인증이 결정되면 가입 또는 설정의 확인 경로와 서버 증빙 검증 계약을 추가한다.

## 4. 감정 선택과 저장

색상 1개를 선택하고 그 색의 단어 1개를 선택한다. 혼합은 서로 다른 색 2개에서 각각 단어 1개를 선택한다. 두 항목을 하나의 구슬로 표시하면서 원본 색·영역·단어 및 카탈로그 버전을 보존한다. 혼합 형태는 피그마 시안을 따른다.

| 색상 | 코드 | 영역 | 단어 순서 |
|---|---|---|---|
| 노랑 | YELLOW | 기쁨·기대 | 기쁨, 기대, 홀가분함, 감사 |
| 주황 | ORANGE | 활력·설렘 | 설렘, 의욕, 뿌듯함, 들뜸 |
| 분홍 | PINK | 애정·다정함 | 애정, 다정함, 그리움, 위로받고 싶음 |
| 빨강 | RED | 강한 감정 | 짜증, 화남, 억울함, 벅참 |
| 보라 | PURPLE | 복잡함·불안 | 불안, 막막함, 복잡함, 생각이 많음 |
| 파랑 | BLUE | 가라앉음 | 가라앉음, 외로움, 무기력, 지침 |
| 초록 | GREEN | 안정·회복 | 편안함, 안정, 회복 중, 평온 |

구슬은 전송 전에는 초안이다. 경로 선택을 완료해 저장·전달이 성공하면 본인 아카이브와 케어에 1회 반영한다. 이는 **작업 기본값**으로, ASMR 생성 대기 중인 초안이 감정 기록에 누적되는 일을 방지한다.

## 5. AI ASMR 플레이리스트

- 선택한 1~2개 감정을 바탕으로 여러 ASMR 음원을 AI로 생성해 **한 구슬에 하나의 순서 있는 플레이리스트**로 묶는다.
- 구슬당 음원 수의 작업 기본값은 3개다. 사용자 결정으로 각 음원은 최대 30초이며 무보컬·무가사다. 3개 기준 한 플레이리스트는 최대 90초다.
- 사용자 음악 설명은 선택 입력으로 받는다. 익명 수신자에게 설명 원문은 전달하지 않는다. 생성에는 선택 감정과 허용된 설명만 사용한다.
- 생성은 비동기다. 대기·생성 중·부분 실패·실패·완료를 표시한다. 실패 음원만 재시도하며 성공한 음원을 보존한다. 완료 전에는 음악 첨부 전송을 막고, 사용자가 첨부를 해제하면 음악 없이 전송할 수 있다.
- 전송 시 플레이리스트를 확정한다. 수신·재열람에서는 저장된 같은 음원을 재생하며 다시 생성하지 않는다.
- 시계 방향 90° 이상 회전 시 첫 곡부터 순서대로 한 번 재생. 반시계 방향 60° 이상 회전·화면 이탈·백그라운드 전환 시 정지. 자동 재생·자동 반복 없음. 작업 기본값으로 정지 후 다시 회전하면 첫 곡부터 시작한다.
- 음악 재생은 최초·과거 수신 단일 구슬 화면에서만 가능. 메인 통합 오브제·상세 팝업은 재생하지 않는다. 제작 미리보기는 감정·생성 상태 확인용이다.
- 한 번에 한 플레이리스트만 재생. 음원 오류가 나도 감정 정보는 확인 가능하며 재시도를 제공한다.

**생성 공급자·실제 생성 시간·비용은 검증 필요.** 크레딧 수량·차감·환급·유료 충전은 최신 FE 계약에 없고 사용자가 음악 생성만 확정했으므로 이번 계약에는 결제 연동을 포함하지 않는다. 공급자와 연결하기 전 실제 생성 성공을 완료로 표시하지 않는다.

| 최초 화면 종료 | 조용히 듣기·닫기 후 반응 기회 종료. 과거 화면은 반응 버튼 없음. 종료 요청 유실 대비 토큰 10분 만료는 작업 기본값 |
| 신고 | 익명 구슬에서 사유 필수. 부적절한 전달 / 반복 원치 않는 전송 / 괴롭힘·위협 / 기타. 기타는 상세 입력 선택 가능 |
| 익명 차단 | 받은 익명 구슬을 통해 발신자를 차단. 신원은 보여주지 않고 이후 양방향 익명 매칭 제외. 기존 수신 기록 유지. 차단 목록·해제 UI는 이번 계약 범위 밖 |

설정 OFF·차단·매칭이 동시에 실행되면 전달 확정 시점의 서버 상태를 검증한다. 취소해도 당일 한도는 돌려주지 않는 것을 작업 기본값으로 둔다.

## 7. 취소·삭제·휴식·알림

- 서버 기준 전송 완료 후 5분 이내이고 해당 수신자가 미열람이면 취소 가능. 친구는 한 대상, 익명은 **대상별 개별 취소**다. 한 대상의 열람이 다른 대상 취소를 막지 않는다.
- 발신 전송 상태는 SENT / PARTIALLY_CANCELLED / CANCELLED. 취소 가능 여부는 대상별 canCancel로 별도 제공한다. 취소·열람 경합은 먼저 확정된 작업을 기준으로 처리한다.
- 취소된 사본은 수신함·수신 기록에서 제거하고 신규 열람을 거절한다. 본인 발신 기록에는 취소 상태를 남긴다. 개인 기록 삭제는 발신자만 숨기며 받은 사본은 유지한다.
- 휴식은 즉시 ON/OFF 또는 일회성 날짜 예약. KST 시작일 00:00 포함~마지막 날 다음 날 00:00 제외. 휴식 중에도 수신함 보관, 푸시 중단. 종료 후 과거 알림을 몰아서 발송하지 않는다.
- 푸시에는 EmOri 식별과 도착 안내만 표시. 감정·음악·사람 정보 없음. 서버에 앱 기기 토큰을 등록해 전달한다. 현재 FE의 15초 폴링은 포그라운드 보조 기능이며 푸시 완료로 간주하지 않는다.
- 최초 및 과거 수신 단일 화면은 글로우, 메인 오브제·팝업은 글로우 없음. Dynamic Island/Live Activities 약 15초 안내는 별도 기술 검토다.

## 8. 기록장·대표 구슬·케어

기록장은 이번 주 포함 최근 12주, 월요일 시작 KST다. 내 감정·프로필 대표 색은 **이번 주 본인 기록에서 가장 많이 선택한 색**으로 정한다. 혼합은 두 색 각각 1회, 동률은 가장 최근 기록에서 선택된 순서 우선, 기록 없음은 무채색 빈 구슬로 표시한다. 삭제·전체 취소 기록은 대표 색과 케어에서 제외하는 작업 기본값을 적용한다. 목록은 cursor를 끝까지 조회하며 100개에서 임의로 자르지 않는다.

케어는 본인이 확정해 기록한 불안·막막함·외로움·무기력·지침만 집계한다. 수신 기록은 제외한다. 오늘 포함 최근 7일 중 4일 이상이면 1단계, 최근 14일 중 10일 이상이면 2단계 우선. 혼합에 하나 이상 포함되면 해당 날짜 1일, 같은 날 여러 건도 1일이다.

홈 카드와 단계별 고정 콘텐츠를 제공한다. 확인·닫기는 단계별 안내 완료로 저장하고 동일 단계 재노출 없음. 기록 삭제 후 집계는 다시 계산하며 안내 완료 이력은 초기화하지 않는다. 조건 미충족 때 카드는 숨긴다. 최종 콘텐츠 문구·지원기관 링크는 기획 제공 필요다. 임의 기관 연락처를 기본값으로 만들지 않는다.
